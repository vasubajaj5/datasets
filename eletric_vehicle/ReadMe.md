# Dataset README

## Overview
This dataset originates from the Washington State Open Data Portal (https://data.wa.gov/) and has been processed to enhance its utility for analysis and research purposes.

## Data Source
- **Original Source**: Washington State Open Data Portal
- **URL**: https://data.wa.gov/

## Data Processing
The original dataset has been synthesized to increase the number of instances (records). This enhancement was performed to:
- Provide a larger sample size for statistical analysis
- Improve model training capabilities
- Enable more robust testing and validation

## Usage Notes
- This dataset contains both original and synthesized records
- Users should be aware that some records are artificially generated based on patterns in the original data
- Appropriate for research, analysis, and educational purposes
- Consider the synthetic nature of expanded records when drawing conclusions
